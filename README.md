# wh11ed — рабочая область

Зонтичный репозиторий продукта **wh11ed** (двуязычный EN/RU справочник по правилам
Warhammer 40k 11 ed + офлайн-трекер партии).

**Здесь нет кода.** Этот репозиторий хранит только оболочку рабочей области: документацию
о том, что сюда входит и как это собрать. Сам продукт живёт в отдельных репозиториях,
которые клонируются **внутрь этой папки** и намеренно занесены в `.gitignore` — вложенными
репозиториями или сабмодулями они не являются.

Такая раскладка сложилась исторически и оставлена сознательно: проекты деплоятся и
версионируются независимо (фронт — в бакет, бэк — в облачную функцию), а словарь вообще
никем не импортируется. Сабмодули связали бы их версии друг с другом без всякой пользы.

## Сборка рабочей области

```bash
git clone <this-repo> 11 && cd 11

git clone https://github.com/Joker1796/wh11ed.git
git clone https://github.com/Joker1796/wh11ed-api.git
git clone <wh-glossary-remote> wh-glossary    # пока только локально, см. ниже

cd wh11ed && npm install && npm run dev       # http://localhost:5173
```

Исходники (PDF, глоссарии) в гит не входят — положить руками, см.
[`sources/README.md`](sources/README.md). Фронт собирается и работает без них.

## Что где лежит

| Папка | Что это | Стек | Репозиторий |
|-------|---------|------|-------------|
| `wh11ed/` | **Фронтенд** — Vue 3 SPA, весь продукт: правила, Event Companion, трекер партии, PWA. Здесь ~99% работы | Vue 3, Vite, Vitest | `Joker1796/wh11ed` |
| `wh11ed-api/` | **Бэкенд** — микросервис облачного бэкапа истории трекера. Нужен только для sync/логина | TypeScript, Hono, YDB, Yandex Cloud Functions | `Joker1796/wh11ed-api` |
| `wh-glossary/` | **Справочник** — общепринятый перевод сообщества (34k пар EN→RU + конвенции). Не библиотека, никем не импортируется | TSV + Python | *(remote не заведён)* |
| `sources/` | Исходники: PDF правил, кодексы, глоссарии. Папка под гитом, содержимое — нет | — | — |
| `CLAUDE.md` | Инструкции для Claude Code: маршрутизация фронт/бэк и стиль работы | — | — |

Подробности по каждому подпроекту — в его собственном `CLAUDE.md`; маршрутизация «куда
смотреть под задачу» — в [`CLAUDE.md`](CLAUDE.md) этой папки.

## Связи между проектами

- `wh11ed` ↔ `wh11ed-api` связаны **контрактом**: `domain/game.ts` на бэке валидирует
  конверт сохранённой партии. Меняя формат партии или auth-флоу на фронте — проверь бэк, и
  наоборот. Это единственное место реальной сцепки.
- `wh-glossary` ни с чем не связан кодом: это справочник для перевода, а не зависимость.
  Его `terms/*.tsv` **грепаются, а не читаются целиком**.

## Заметки

- `wh-glossary` пока существует только локально — remote не заведён. До пуша вторая машина
  его не получит.
- Корневой `CLAUDE.md` до этого репозитория был вне гита, поэтому указатель на словарь
  продублирован в `wh11ed/CLAUDE.md` — он доезжает до второй машины сам.
