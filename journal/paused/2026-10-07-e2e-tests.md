# Сквозные тесты в браузере

## Откуда

Предложение контрибьютора Creego (2026-10-07, в переписке с владельцем): прогонять проверки
автоматически, вплоть до Cypress. Юнит-тесты, линт, паритет, `imghash` и сборка уже идут в CI
(`.github/workflows/ci.yml`) на каждый PR и push в `main`/`release/**`. Сквозных (e2e) нет.

## Что уже есть

- `npm run smoke` — Chrome через `playwright-core` прокликивает 9 тестовых ростеров на двух
  ширинах: ошибки JS, боковая прокрутка, сырая разметка. Запускается руками перед релизом.
- `npm run a11y` — контраст, тап-цели, переполнение, шрифт Sofia ≤18px вес 400.
- Снимки вёрстки — скрипты в scratchpad, не в репо.

## Варианты

- **(а)** `npm run smoke` в CI на каждый PR — +2–3 мин на прогон; нужен Chrome в раннере
  (`playwright-core` + `channel: 'chrome'` или скачанный chromium). Дешевле всего.
- **(б)** Свой набор сценариев на Playwright Test (собрать ростер, начать партию, синхронизация) —
  несколько дней работы, поддержка при каждой переделке интерфейса. Cypress не брать:
  `playwright-core` уже в проекте.
- **(в)** Отдать (б) Creego, раз он предложил.
