# Юнит в модалке на телефоне, просмотр и сравнение на десктопе

## Зачем

Вкладка «Юниты» фракции (`/factions/:slug/datasheets`) — сетка карточек, каждая ведёт на
отдельную страницу юнита (`/factions/:slug/datasheets/:unit`, верхнеуровневый маршрут). После
перехода к юниту и возврата к списку позиция экрана теряется — игрок листает сетку заново.
Владелец (2026-10-04): чинить не запоминание позиции, а сам переход.

- **Телефон:** тап по карточке открывает юнит в модалке поверх списка. Список не уходит со
  страницы, позиция не меняется вообще; юниты удобно смотреть подряд.
- **Десктоп:** режим просмотра и сравнения — слева список, справа один юнит или два рядом.

## Что не меняется

- Страница юнита как маршрут остаётся: на неё ведут поиск, ссылки, SEO (своя HTML-страница на
  каждый юнит, `gen-seo-routes`). Модалка — второй способ показать тот же юнит, не замена.
- Карточка юнита одна — `DatasheetCard`; шапка страницы (имя, ⭐, пин, «…», база) сейчас живёт в
  `FactionDatasheetView` и должна стать общей, а не копией (`npm run dupes`).

## План (черновик, до ответов владельца)

1. **Вынести «юнит целиком» в компонент.** Шапка + `DatasheetCard` + действия страницы
   (`FactionDatasheetView` → общий компонент), страница рисует его без изменений. Чистый
   рефакторинг, проверка — снимки страницы до/после.
2. **Модалка на телефоне.** Тап по карточке в сетке на узком экране открывает `BaseModal` с этим
   компонентом. Back закрывает (`useBackToClose` уже даёт). Ссылки внутри карточки (лидер →
   отряд, keyword → список юнитов) меняют юнит в той же модалке, а не уводят на страницу.
   Данные фракции на вкладке уже загружены — модалка открывается без ожидания.
3. **Десктоп: список + юнит.** Вкладка «Юниты» на широком экране — две колонки: список слева,
   выбранный юнит справа (своя прокрутка у правой колонки, список стоит). Выбор в адресе
   (`?unit=…`), чтобы Back и ссылка работали.
4. **Сравнение.** Второй слот справа: два юнита рядом. Способ добавить второй — по ответу
   владельца.
5. **Проверки и доки.** Playwright: пролистать сетку, открыть/закрыть юнит — `scrollY` тот же;
   снимки 320–414 и десктоп; `a11y`/`smoke`; `src/views/faction/CLAUDE.md`; чейнджлог.

## Кнопка «поделиться юнитом» (к ответу 1)

Сейчас в «…» юнита: закрепить, ⭐, скопировать название, лор, поиск картинки; `navigator.share`
в приложении нигде не используется, копирование ссылки уже есть у приглашения в партию
(`PartyInvite.vue`). Варианты, предложенные владельцу 2026-10-04:

- **А. «Скопировать ссылку»** рядом со «Скопировать название» — везде одинаково, отклик ✓ на иконке.
- **Б. «Поделиться»** — системное окно телефона (Telegram, VK…); на десктопе поддержка
  разная, нужен запасной путь копированием.
- **В. Один пункт, который подстраивается** — где есть системное окно, «Поделиться», где нет —
  «Скопировать ссылку». **Моя рекомендация.**
- **Г. Своё окошко** — ссылка, «Скопировать», Telegram, VK, может быть QR для соперника за
  столом. Новый экран на поддержку; без QR почти не лучше В.

Подвопросы: на десктопе шестая иконка в ряд у имени или только в «…» на всех экранах; ссылка —
на текущий язык (`/ru/…`), у юнита своя SEO-страница, превью в мессенджере покажет имя.
