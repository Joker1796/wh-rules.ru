# Гейт вёрстки `npm run a11y` и что он нашёл в палитре

Сделано 2026-09-21 (wh11ed `43f6f71`, `ced4570`; в проде с v2.6.5): `scripts/check-a11y.mjs`
гоняет 18 маршрутов × EN/RU × light/dark × 390/1280px в установленном Chrome через
`playwright-core` (браузер не качает) и меряет WCAG-контраст текста, тап-цели ≥24px, боковой
скролл. Baseline `scripts/lib/a11y-baseline.json` — 124 записи, все по палитре; гейт краснеет
только на новое, протухшие записи печатает. Исключения (`ALLOWED`): два плотных оглавления и
булавки чипов — плотность важнее 24px. Описание — `src/components/CLAUDE.md`, раздел про гейт.

Толчок: токен `--danger` (`eff1bb9`) показал ~15 мест, где ошибки месяцами были тёмно-бордовыми
на тёмной теме — никто не смотрел на экран, только на стили.

## Решения, которых ждём (цифры — измеренные)

| Что | Сейчас | Предложение |
|---|---|---|
| Light `--text-muted` на `--bg-secondary` (16 мест) | `#686957` → 4.24 | `#5e5f4e` → 4.93 |
| Light `--text-dim` (21 место) | `#8a8b78` → 2.6–3.2 | `#6f705d` → 4.28, всё равно < 4.5: либо исключение, либо dim = muted + меньший кегль |
| Dark `--text-dim` | `#7e7e72` → 3.2 | `#9c9c8e` → 4.7 |
| Dark `--accent` как текст (27 мест) vs как фон под белым (12) | `#c8585e` → 2.8–3.7 / 4.19 | разделить: заливки `#b8474d` (белый на нём 5.2), текст новым `--accent-ink: #e8858b` (5.1) |
| Зелёный орков как текст чипов | `#467a1e` → 3.7–4.4 | в `FactionAccentScope` подмешивать 15% чёрного для текстовых ролей; проверить остальные фракции гейтом |

Точечные ошибки, не токены: `strong` «CRITICAL HIT» `#3d282a` на `#027360` = 2.35 (light);
бейдж FAQ «A» белым на `#a8a89a` = 2.4 (dark).

Гейт не ловит «не тот цвет» (белый вместо красного проходит по контрасту) — так прошёл
`{red:RED}` в тёмной теме (`76e719f`). Идея: vitest-снимок цветов `{red/blue/green}` в обеих темах.
