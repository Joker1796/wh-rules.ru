## Где остановились (20.10, поздний вечер)

`release/2.10.1` (wh11ed) = `79d623b7`, не запушен. После `03f2a89b` (последний полный прогон) влиты:
туториал (первая группа каталога, демо-юнит) и **`fix/ledby-flicker`** — жалоба владельца с Android:
аккордеон «Кто возглавляет» в карточке юнита из каталога дёргался в такт печатающемуся примеру
поиска. Механизм: текст примера (`useTypingPlaceholder`) читался хозяином → каталог
перерисовывался на каждую букву → `:ctx="{…}"` давал карточке новый объект → `watch(() => [slug,
id])` (новый массив = «изменилось») очищал и грузил список заново. Класс закрыт: пример рисует
только `TypingGhost` (`ghost` = markRaw-обёртка над ref), 9 вотчеров переведены на
`watch([() => a, () => b])`, TourOverlay пишет rect только при сдвиге, SyncIndicator тикает только в
партии, участники лобби — только при изменении, литералы в шаблонах трекера/редактора → computed.
Гейты: `src/watchSources.test.js`, `src/components/TypingGhost.test.js` (оба красные на старом).
Замер (6× CPU, 8 с): 56 перезагрузок блока → 0, худший кадр 67 → 17 мс. Не тронуто: чипы на строках
`RosterViewView` (`pinnedChipOf` в v-for) — дёшево, не периодично. Журнал ошибок прода этого не ловил
(не исключение).

**Следующий шаг:** «катить на бету?» → полный прогон (vitest --maxWorkers=2, build, sync) → бета →
смотрит владелец (в т.ч. плавность анимаций на его Android) → сайт `BUMP=none` → посты ВК/ТГ. api
`dcc4cac` не запушен, выкат api — командой владельца. Скриншоты/скрипты сессии — в scratchpad.

## Михаил, 2026-10-20 — сброшенную вторичку можно засчитать — СДЕЛАНО (`49b78282`)

Игрок в свой ход сбрасывает вторичку из её меню: «Сбросить, получить CP и закончить ход». Открывается окно
отметки VP, и в нём есть та самая сброшенная вторичка: её можно отметить выполненной — и CP за сброс тоже
придёт. Ожидаемо: сброшенная карта в окне подсчёта конца хода не предлагается (или сброс идёт после
подсчёта, без неё). Разобрать по §2а: механизм, другие пути сброса (без «закончить ход»), гейт.
