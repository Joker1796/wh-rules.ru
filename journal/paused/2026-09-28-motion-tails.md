# Хвосты прохода по анимациям

Сам проход выкачен в v2.7.5; здесь то, что осталось открытым.

1. **iOS вживую.** Всё мерилось в Chrome с эмуляцией iPhone 13 (покадрово, CPU 4×). Настоящий
   Safari не проверялся: WebKit для playwright не установлен (`npx playwright install webkit`,
   ~100 МБ). Владелец собирался посмотреть на своём телефоне перед постом в ВК.
2. **Окно «Правила фракции» на телефоне.** Аккордеон при раскрытии растягивает окно до максимума —
   предложено открывать окно сразу на полную высоту. Ответа не было.
3. **Трекер.** Общие примитивы (прокрутка числа в `NumberStepper`, бегунок `.seg`, нажатия
   `.btn-*`) действуют и там; конфликт при слиянии ветки редизайна записан в её журнале
   ([2026-08-26-cp-tracking](2026-08-26-cp-tracking.md)).
4. **2026-09-29: сдвиги сняты целиком** (владелец: «дёргано»). Все переключения внутри страницы и
   все переходы между страницами — затухание; режимы конструктора держатся построенными.
   Не в проде — ждёт выпуска 2.7.6 ([журнал](2026-09-29-release-2.7.6.md)).
