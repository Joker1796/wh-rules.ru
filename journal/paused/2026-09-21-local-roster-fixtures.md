# Локальные фикстуры ростеров для просмотра правок

Владелец теряет тестовые ростеры между просмотрами: `localStorage` привязан к origin, а
`npm run dev` (5173), `npm run preview` (4173) и прод — три разных хранилища. Отложено
2026-09-21.

Предложено: файл `dev/rosters.local.json` в `.gitignore`; в dev/preview при пустом хранилище
приложение подсасывает его; кнопка «сохранить текущие в фикстуру» только под `import.meta.env.DEV`.
Облачный вход с localhost отвергнут (CORS/OAuth-редиректы бэкенда, риск записать мусор в прод).
Пока обход — смотреть всегда на одном порту (4173).
