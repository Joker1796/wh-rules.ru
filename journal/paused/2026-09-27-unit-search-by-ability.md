# Поиск юнитов по способностям и keywords

## Сделано — wh11ed `3644ffa`, В ПРОДЕ с v2.7.4 (2026-09-28)

Юнит находится по названиям способностей (свои, wargear, core, правило фракции; EN + RU-заголовок,
где оверлей его переводит) и keywords — в трёх местах: общий поиск Ctrl+K, поле на странице
датащитов фракции, каталог конструктора. Один матчер `src/composables/datasheetTags.js`, данные —
отдельный генерируемый чанк `src/data/datasheetTagIndex.js` (тот же `gen-datasheet-index.mjs`,
349 КБ / 113 КБ gzip), грузится с запроса от 3 символов. `localizeSheet` вынесен в
`datasheets/ru/localize.js` (Node не импортирует `import.meta.glob` из `ru/index.js`).
Покрытие: все 1361 юнит конструктора имеют теги. В Ctrl+K тег-хиты со счётом 0.9 (ниже имён),
тег — подстрочником. Проверено в браузере (орки, Blood Angels со сложенными SM), 2081 тест.

## 2026-09-28 — анимация примеров во всех полях поиска + RU-алиасы (wh11ed `81b0d6b`, не в проде)

Просьба владельца: «во все строки поиска анимацию с вариантами, как в поиске по сайту». Решения
владельца: примеры — юнит, своя способность фракции, core-способность, keyword + (его добавка)
RU-алиас юнита; в конструкторе — только своя фракция, без союзников; анимация идёт, пока поле
пустое (не только по фокусу).

- **Примеры генерирует `gen-datasheet-index.mjs`** → `src/data/datasheetSearchExamples.js`
  (`{ slug: [[юнит, способность, core, keyword], ruAlias] }`, ~3 КБ): юнит — самый короткий
  Battleline с главным faction keyword фракции (чтобы не Ynnari у Aeldari, не Plaguebearers у DG);
  способность — своя (не core, не правило армии, не «Damaged»), у ≥2 юнитов, самая частая;
  core — первая из списка предпочтений у ≥2 юнитов; keyword — Fly/Psyker/Monster/…; алиас —
  находящий больше всего юнитов. Длина ≤22. Тест `datasheetSearchExamples.test.js` набирает каждый
  пример всех 30 фракций тем же матчингом, что поле.
- **RU-алиасы ушли в индекс тегов** — «бойз»/«термосы» теперь находят юниты на странице фракции и
  в каталоге конструктора (раньше — только Ctrl+K). Проверено в браузере: «бойз» у Orks → 5 юнитов.
- **Союзники в поиске конструктора находятся** (по имени, EN- и RU-способности) — проверено
  пробным тестом на Inquisitor у SM; в примеры их не берём.
- **Общий `TypingGhost.vue`** (три поля) + глобальный `.typing-field`; `useUnitSearchExamples.js`
  ставит на паузу вне экрана (IntersectionObserver) и в фоне. В узком поле (каталог на телефоне
  ~9 символов) строка прокручивается как настоящий input — видно конец и каретку.
- Гейты: 2132 теста, lint, dupes, radii, a11y, build — зелёные. Доки: wh11ed `CLAUDE.md` (Search),
  `src/data/CLAUDE.md` (RU search aliases).

**Открыто (сказано владельцу, ответа нет):** у большинства фракций core/keyword = Deep Strike/Fly
(однообразно); у DG, Drukhari, EC, WE нет своей способности на ≥2 юнитах, у Chaos Knights — только
юнит, Walker и алиас; кое-где пример не для новичка («Cherub», «Split»). Предложен список ручных
замен — не просил.
