> git-коммита) — коммитить по ходу дела, как `DATA-9NN-TODO.md`-хендофф в `two-machines-workflow`.
> **Сжат 2026-08-03**: полные таблицы «юнит → алиас» по каждой партии убраны — это дублирует

## Идея

Поиск (Ctrl+K) искал юнитов только по точному вхождению английского имени. Русскоговорящему
не всегда очевидно английское написание (особенно нарочно исковерканные ксено-имена), плюс у
части юнитов есть устоявшиеся в сообществе прозвища (Ghazghkull → «Газя»). Решение — скрытое
поле `aliasesRu`, влияющее только на поиск, никогда не отображаемое как «имя» юнита (имена
юнитов остаются английскими — жёсткая конвенция, `CLAUDE.md` → Bilingual content conventions).

## Механизм (код, не трогать без причины)

1. `src/data/datasheets/ru/<slug>.js` — опциональное поле `aliasesRu: string[]` на юните в
   RU-оверлее (рядом с `flavor`/`abilities`). Один конкретный именной персонаж — грепать код.
2. `src/data/datasheetAliasRulesRu.js` — алиасы по ПАТТЕРНУ EN-имени для целого класса юнитов
   разом (все Terminator-датащиты → «термосы» и т.п.), 36 правил, `{ pattern: RegExp,
   aliasesRu: string[] }`.
3. `scripts/gen-datasheet-index.mjs` — сливает оба источника (`aliasesFor(name, personal)`) в
   `src/data/datasheetIndex.js`, третий элемент записи юнита `[id, name, aliasesRu | null]`.
   Печатает в консоль `N with aliasesRu`.
4. `src/composables/useSearch.js`'s `searchDatasheets()` — алиас проверяется, только если своё
   имя не совпало; совпадение по алиасу кладётся в `titleRu` (RU-локаль) — та же подпись, что у
   стратагем/детачментов. Матчинг по алиасу работает независимо от локали.
5. **После любой правки алиасов:** `node scripts/gen-datasheet-index.mjs`, затем `npm test &&
   npm run build` перед тем, как считать партию законченной.
6. Тесты: `useSearch.test.js`, `describe('datasheet unit search')` — 4 кейса, часть `263/263`.

## Как добавить алиас дальше

**Персональный (один юнит, обычно именной персонаж):**
1. `src/data/datasheets/ru/<slug>.js`, блок по `id` (совпадает с EN-файлом) — **сверить `id`
   заранее**, GW иногда переименовывает персонажей между редакциями (см. «Гочи» ниже).
2. **Сначала проверить, нет ли уже готового RU `flavor` в том же файле** — если есть,
   транслитерация оттуда обычно побеждает глоссарий (это то, что реально видит игрок на
   странице; алиас, который ему противоречит, хуже отсутствующего). Один раз пользователь явно
   предпочёл глоссарий вместо файла (Huron Blackheart, см. «Гочи») — по умолчанию всё равно
   сначала смотреть файл, но финальное слово за пользователем при ревью.
3. Если файл молчит — `grep -i "<имя>" ../wh-glossary/terms/*.tsv`. Ничего — пропустить и
   отметить как неподтверждённое, не гадать.
4. Добавить `aliasesRu: [...]` первым полем блока с комментарием `// Search-only aliases (see
   ALIASES-PROGRESS.md) — never displayed as the unit's name.`
5. `node scripts/gen-datasheet-index.mjs`.

**Паттерн на класс юнитов:** правило `{ pattern: /\bWord\b/i, aliasesRu: [...] }` в
`datasheetAliasRulesRu.js` — сначала сверить реальное EN-имя датащита (`grep '"name":'
src/data/datasheets/*.js`), GW-имена не всегда совпадают с ожиданием (Nobz не Nobs,
Immortals/Obliterators — множественное число). Так же регенерировать индекс.

**Реальный бэклог именных персонажей на фракцию** — не полагаться на память, грепать:
`grep -B2 "EPIC HERO" src/data/datasheets/<f>.js`.

## Правила отбора (чтобы не наплодить мусор)

- **Транслитерация** — предпочтение: 1) уже существующая в RU `flavor` того же файла,
  2) `wh-glossary`, 3) бесспорная (не исковерканная GW) транслитерация с нуля. У GW много
  намеренно исковерканных имён (орочьи, тиранидские, стилизованные «монгольские» типа Kor'sarro
  Khan) — наивная транслитерация там даст мусор, лучше пропустить и спросить пользователя.
- **Прозвища/сленг** — только реально устоявшиеся в русскоязычном сообществе, не выдумывать
  самому. Неверное прозвище хуже отсутствующего.
- **Апостроф → добавить слитный вариант.** Русскоговорящие обычно не печатают апостроф —
  каждый алиас, содержащий апостроф внутри слова (`Мефет’ран`, `Аза’город`, `Ri'Lantar`-style),
  должен иметь рядом слитный дубль без него (`Мефетран`, `Азагород`). Не убирать апострофную
  версию — обе формы должны присутствовать.
- **Не для каждого юнита** — рядовые юниты с генеричными названиями почти никогда не нуждаются
  в алиасах. Приоритет — Epic Heroes/именные персонажи с неочевидным написанием.
- **Ревью перед коммитом:** пользователь лично просматривает этот файл в IDE перед каждым
  коммитом партии — не коммитить самостоятельно, ждать подтверждения/правок.

## Гочи (нетривиальные находки — держать в голове на будущее)

- **id ≠ ожидаемое имя после ретемы GW:** Szarekh → карточка называется `the-silent-king`;
  Ursarkar E. Creed → актуальная карточка `ursula-creed` (Ursula Creed, GW заменила персонажа).
  Всегда грепать `"name":` в EN-файле, не полагаться на память при выборе `id`.
- **Акцентированные буквы пропадают из `id`, но не из `name`:** `Khârn the Betrayer` →
  `kh-rn-the-betrayer`; `Ûthar the Destined` → `thar-the-destined` (без `Û`). ASCII-only grep по
  имени пропускает такие юниты — грепать `EPIC HERO`/`"name":` напрямую, не полагаться на
  ASCII-паттерн вида `grep -i "Uthar"`.
- **Запрошены пользователем, но юнита нет в датасете вообще** (проверено исчерпывающим
  grep'ом по `src/data/datasheets/`): Kharn the Betrayer, Asdrubael Vect, Urien Rakarth,
  Kaldor Draigo.
- **Файл и глоссарий расходятся** — по умолчанию побеждает файл (игрок его видит), но
  один раз пользователь при ревью явно предпочёл глоссарий: Huron Blackheart — «Гурон»
  (глоссарий), а не «Хурон» (`flavor` файла). Отдельные внутренние расхождения по фракциям
  (не ошибка, просто два независимых перевода): Rotigus → файл «Ротигус», глоссарий «Гнилиус»;
  Wazdakka Gutsmek → файл «Гатсмек», глоссарий «Гутсмек»; Njal Stormcaller → файл «Ньял
  Буревестник», глоссарий «Ньяль Зовущий Бурю».
- **Некоторые датащиты специально держат имя английским в самом `flavor`** (Illuminor Szeras,
  Imotekh, Orikan, Kairos Fateweaver, The Changeling, Cypher, The Visarch, The Yncarne,
  Murderfang, Darkstrider) — там алиас берётся из глоссария без конфликта с текстом на странице.
- **Алиас матчится по ВХОЖДЕНИЮ подстроки** (`useSearch.js` → `a.toLowerCase().includes(q)`),
  поэтому короткая форма, целиком входящая в длинную, находимость НЕ расширяет: при алиасе
  «рыцарь-квесторис» запрос «квесторис» и так попадает. Такие дубли влияют только на подпись
  `titleRu` в выдаче — берётся ПЕРВЫЙ совпавший элемент массива, так что длинную/информативную
  форму держать первой. Добавлять короткую форму отдельным элементом нужно лишь когда она не
  подстрока (Armiger → «Армигер» + «рыцарь-оруженосец», Warglaive → «варглейв» + «глевия»).
  Побочный эффект той же подстрочности: «еррант» (Knight Errant) заодно матчит «аберрант» —
  такой шум приемлем, оба результата релевантны своим запросам.
- **Один паттерн — два разных юнита в разных фракциях:** `Abominant` есть и у Genestealer
  Cults (мутант, «изрожденец»), и у Chaos Knights (`Knight Abominant` — рыцарское шасси).
  Лечится якорением: `/^Abominant$/i` для GSC + отдельное `/Knight Abominant/i`. Перед
  добавлением паттерна ВСЕГДА прогонять его по всем `"name":` из `src/data/datasheets/*.js`,
  а не только по целевой фракции. Обратный, желательный случай той же природы — шасси
  Questoris/Cerastus/Acastus, которые намеренно ловят и Chaos Knights-копии («Chaos Cerastus
  Knight Lancer»): та же машина, то же русское название. А `Moirax` оставлен голой
  транслитерацией именно потому, что ловит ещё и `War Dog Moirax` — War Dog не Armiger, и
  «оруженосец» ему прилетать не должен.
- **Общая категория "пропущено, не гадать"** — стилизованные "монгольские"/деформированные
  имена (Kor'sarro Khan, Suboden Khan), персонажи без глоссария и без бесспорной
  транслитерации (Adrax Agatone, Prince Yriel, Kharseth, Lhykhis, Shalaxi Helbane, The Blue
  Scribes, The Masque of Slaanesh, Syll'Esske, Haarken Worldclaimer, Kravek Morne, Nekrosor
  Ammentar, Ephrael Stern, Intranzia Fraye, Aestred Thurga/Agathae Dolan, Lord Marshal Dreir).
  **Список стоит перепроверять грепом, а не помнить:** Shalaxi Helbane, The Blue Scribes,
  The Masque of Slaanesh и Syll'Esske числились здесь, а в батче 20 первые два нашлись в
  глоссарии («Шалакси Адский Бич», «Голубые писари»), остальным два дали транслитерацию.
