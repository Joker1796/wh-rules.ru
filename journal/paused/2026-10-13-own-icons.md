# Свои иконки вместо Bootstrap Icons

## Решение владельца (2026-10-13)

Иконки Bootstrap заменяем **своими рисунками** — пак владельца (`.wi`, `src/assets/icons/`,
`src/components/CLAUDE.md` → «App icons»). **SVG Bootstrap в проект не кладём** и не выдаём за
свои, даже временно, хоть лицензия MIT это и позволяет: «не хочу выдирать чужие иконки и класть
как своё». Делается **отдельным прогоном по команде владельца**, не попутно.

## Зачем

Сейчас из 2078 иконок пакета используется 65 (211 мест в 77 файлах, имён, собранных в коде из
кусков, нет). За них посетитель платит шрифтом 134 КБ (грузится при первой же иконке, до этого
иконки пустые) и 74 КБ CSS (13 КБ сжатого) — классами всех 2078. Свой пак — маски в CSS, ~0,5 КБ
на рисунок: те же ~8–10 КБ сжатого, без шрифта, без мигания, одна система иконок вместо двух.

По весу свой рисунок и урезанный до 65 значков шрифт почти равны — урезание (вариант «А») было бы
быстрее, но владелец выбрал свои рисунки: это вопрос стиля, а не байтов.

## Как будет выглядеть прогон

1. Список используемых — скрипт по `src/` (так считали 2026-10-13: шевроны `chevron-down/right/
   left/up` — 67 мест из 211; затем `info-circle` ×11, `exclamation-triangle-fill` ×10,
   `question-circle` ×8, `slash-circle` ×7, `arrow-counterclockwise` ×7; остальное по 1–5).
   Пересчитать в день прогона, не брать этот список на веру.
2. Владелец рисует (или выбирает из своего пака: часть, вероятно, уже есть — `check`, `add`…).
   Шевроны — один рисунок: `ChevronIcon.vue` уже поворачивает один глиф.
3. Замена классов `bi bi-x` → `wi wi-x`, удаление `bootstrap-icons` из зависимостей и из
   `src/fonts.js`.
4. Гейт: тест, падающий на любое `bi bi-…` / `bi-` в коде, — чтобы шрифт не вернулся.
5. Снимки каждой заменённой иконки на стенде владельцу до «готово».
