# Замеры производительности — в следующий релиз (2.10.2)

Повод: баг с дёрганьем аккордеона на Android (исправлен в 2.10.1, `fix/ledby-flicker`) нашёл
владелец, а не гейт: производительность у нас не мерил никто. Владелец: «сделай оба в следующий
релиз».

## 1. Полевые замеры с телефонов игроков

Тем же каналом и с тем же согласием, что и ошибки (отправка выключена по умолчанию, спрашиваем
вошедшего игрока после ошибки). Агрегаты, никого не опознаём.

- **API — готово**, ветка `feat/client-perf` в wh11ed-api (`eede6d8`, `666ed8d`), не запушено:
  - миграция `004_client_perf.sql`;
  - `POST /errors` принимает `perf: [{ route, inp, longN, longMs, secs }]` (до 8) и `device` (`c8m4`);
  - `src/db/clientPerf.repo.ts`;
  - `scripts/perf-list.ts` (`--by=browser|device|version`);
  - digest чистит через 90 дней;
  - README.

  Unit-тесты (125) и тест на Postgres зелёные. Порядок выката неважен: старый API молча
  отбрасывает `perf`, потому что zod срезает лишние ключи. Миграцию накатывает вход контейнера.
  Выкат — только командой владельца.

  На стенде падает `test/db/party.test.ts` → «seats: … a revoked token resolves to nobody». Файлов
  партии ветка не трогает. Разобрать отдельно, не здесь.
- **Клиент — не начат.** Ветка `feat/perf-metrics` в wh11ed от `release/2.10.1`, пустая. План:
  - `src/composables/perfReport.js`. `PerformanceObserver` на `event` (durationThreshold ~40,
    `interactionId > 0` → максимум за экран) и на `longtask` (число и сумма). Экран — шаблон
    маршрута из `router.currentRoute.matched.at(-1).path` без `/:lang(ru)?`. Время экрана — только
    пока страница видима; переключение по `router.afterEach`.
  - Отправка: на `pagehide` / `visibilitychange: hidden` — только при `reportsOn()`. Новая функция
    в `useErrorLog.js` шлёт `payload({ perf, device })`.
  - Устройство: `c${min(cores,16)}m${navigator.deviceMemory||0}`.
  - Установка в `main.js` после `app.use(router)`.
  - Тесты на сбор и на «без согласия — ничего».

## 2. `npm run perf` — лабораторный гейт перед релизом

Не начат. Основа — `scripts/smoke.mjs`: `vite preview`, засев тестовых ростеров через
`addInitScript`, системный Chrome. Плюс замер из сессии 20.10: CPU throttling ×6 через CDP,
MutationObserver на ВСЮ карточку (не на блок — пропавший блок наблюдатель не видит), longtask,
кадры rAF. Сценарии:
- **Простой** (8 с): каталог с открытой карточкой, сетка юнитов фракции, поиск, экран партии,
  просмотр ростера.

- **Отклик**: добавить юнит, сменить вооружение, засчитать вторичку, конец фазы.
