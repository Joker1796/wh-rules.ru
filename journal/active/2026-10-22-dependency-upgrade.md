# Обновление зависимостей

Поводом стал аудит 22.10: у API есть уязвимости high и moderate в hono, @hono/node-server и source-map-js, у сайта — high в vite. Ни одна из них по нам не бьёт: `serveStatic`, `parseBody` и `hono/jsx` мы не используем, карты исходников только наши, сервер разработки слушает только локально. Caddy 2.10.2 на сервере несёт около 20 CVE. Они в FastCGI, `vars_regexp`, file- и host-матчерах, а в нашем Caddyfile только `reverse_proxy` и `redir`.

## Принцип

- **Сайт — статический бандл,** поэтому его проверяем локально досконально и обновляем разом (решение владельца). Сравниваем сборку с `main` (файлы, размеры, офлайн-кэш, `sw.js`), затем полный прогон. Локально не проверить только Safari и iOS — это закрывает бета на телефоне владельца.
- **API и сервер — живые данные и простой,** поэтому по шагу на выкат, откат готов, ночью, с бэкапом.

**Шаг 1. Мелкие обновления.** hono 4.13.13, @hono/node-server 1.19.17, tsx 4.23.15, postgres 3.4.9, nodemailer 10.2.0, source-map-js 1.2.2.

- Для нашего Caddyfile существенного нет:
  - заголовки с `_` и `.` теперь выбрасываются, а у нас только `X-101` и `X-Forwarded-For`;

- Проверить после: сертификаты, HTTP/3, 301 со старого домена, что ограничитель видит настоящий IP.
- Делается в одно ночное окно с перезагрузкой сервера.

**Шаг 3. @hono/node-server 2.1.5.**
- Тело запроса читается напрямую из `IncomingMessage` (`c.req.json()` во всех маршрутах).
- Проверить:
  - битый JSON → 400 `invalid_json`;
  - пустое тело в `/auth/resend`;
  - партия 512 КБ;
  - 304 по ETag (`prefs.ts:39`, `broadcast.ts:115`);
  - `Set-Cookie` при refresh.

**Шаг 4. Node.**

**Шаг 5. zod 4.6 и zod-to-openapi 9.1** (8.0 требует zod 4, 9.0 ломает только типы).
- Сайт читает из ответов только `data.error`, форму ошибок zod наружу мы не отдаём. Значит, сравниваем только вердикт и результат разбора.
- Точки внимания:
  - `.int()` теперь только безопасные целые, `z.number()` не пускает Infinity — это версии и метки времени;

  - с 4.4 ключи `z.unknown()` стали обязательными (`openapi/party.ts:27`);
  - `.passthrough()` и `.strict()` устарели, но работают.
- Сравнение бок о бок: `zod/v4` внутри 3.25 — это примерно код 4.0, правила 4.4+ в нём не видны. Поэтому сравнивать установленным zod 4 против `zod/v3` из него же.
