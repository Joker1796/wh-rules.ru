# Моноширинный шрифт разный на Android и остальных

## Что видно

Владелец сравнил свой Android-телефон (Xiaomi, Яндекс.Браузер) со стендом на Mac: бейджи
«Основные · Ивенты · Комбат патруль», «30 фракций», цены DP, номера версий набраны разными шрифтами —
на Android тонкий без засечек, на Mac машинописный Courier с засечками.

## Почему

`--font-mono: 'Courier New', Courier, monospace` (wh11ed `src/style.css`) — единственный шрифт сайта,
который берётся из системы. Courier New есть на Mac, iOS и Windows; на Android его нет, и браузер
подставляет системный monospace телефона (у разных производителей разный). Inter, Sofia Sans и
EB Garamond self-hosted через `@fontsource` и одинаковы везде. Моно используется примерно в 48 файлах.

## Варианты (предложены владельцу)

1. Свой моно-шрифт через `@fontsource`, как Inter:
   - (а) современный, как на Android: JetBrains Mono / Roboto Mono / IBM Plex Mono (все с кириллицей);
   - (б) «машинописный», как сейчас на Mac: Courier New отдавать нельзя по лицензии; свободных
     машинописных с кириллицей мало (Courier Prime, по памяти, без кириллицы — проверить).
   Цена ~+20–30 КБ на начертание (латиница + кириллица, woff2), попадает в офлайн-набор; почти всё
   моно жирное — хватит одного-двух начертаний.
2. Оставить как есть — выбрано 2026-10-05.

Моя рекомендация была 1(а): JetBrains Mono или IBM Plex Mono — читается в мелких чипах, Android почти
не меняется.

## 2026-10-31 — решено: Kibernetyk Mono
Владелец выбрал Kibernetyk Mono (Pavlo Kilko, OFL 1.1, github.com/PavloKilko/KibernetykMono) и для
лора, и для всех моно-мест. Я советовал лор не трогать (шире на ~50%, нет курсива), владелец решил
заменить — решение окончательное.
- wh11ed `feat/lore-font` `010702df` (от main 2.10.9): `src/assets/fonts/kibernetyk-mono*.woff2`
  (400/600/700, по ~12 КБ, целиком, все 595 глифов) + `kibernetyk-mono.css`, `--font-mono` = он;
  `--font-serif` и `@fontsource/eb-garamond` удалены. Весь лор (список «скрыть лор» + лор датащитов,
  вводная Core Rules, лор миссий, flavor-блоки Event Companion) — без курсива, размер ~0.82rem.
- Офлайн: −120 КБ Garamond, +36 КБ Kibernetyk.
- Гейты: `fontFaces.test.js` и `font-faces.mjs` переведены на Kibernetyk, курсив моно — ошибка.
  lint, 3854 теста, сборка, `npm run a11y` (168 загрузок) — чисто. a11y сообщает устаревшую запись
  базы `contrast · dark · a.cl-link` — не разбирал, связана ли с заменой.
- Dominatus (`feat/dominatus` `4d12f5f5`): лор карт, тексты исходов и подпись «2093-AR:VOLCANUS» —
  тоже им.
