# Страница изменений правил GW («Патчи»)

Игроки жалуются, что изменения правил разбросаны: эррата в приложении, очки в MFM, FAQ отдельно.
Одна страница — лента патчей, внутри фракции, внутри «было → стало».

## Решения владельца (2026-10-01)

- Источники: правила из приложения (appdata), очки (MFM), FAQ и эррата, новые фракции/кодексы.
- Подробность: «было → стало» — чипы для чисел (`T 4 → 5`), подсветка слов в тексте.
  Генерируется из данных, без ручного пересказа.
- Период: все версии, что есть в истории appdata, лентой по патчам; дальше пополняется на каждом
  бампе.
- Место: свой пункт в шапке на компьютере; на телефоне — боковое меню (нижняя панель не меняется).
- Текст в RU: старые патчи — английский текст изменений (старых RU-переводов нет), подписи и числа
  на двух языках; **с ближайшего бампа переводим и «было», и «стало»**.

## План

1. Генератор + фильтр шума на 946→963, список показать владельцу до вёрстки.
2. Бэкфилл остальных версий, MFM, FAQ → файл на патч в `wh11ed/src/data/patches/`, грузится
   только страницей.
3. Страница `/patches`: лента, фильтр по фракции (по умолчанию закреплённые), ссылки на юнитов.
4. Шаг в скил `appdata-update`: каждый бамп добавляет патч (+ RU «было/стало»).
