## Что в `release/2.8.2` (`30090511`, запушена 13.10 для Creego, не выкачена)

- **Союзники: ни Warlord, ни улучшения** (`fix/ally-enhancements`, `1857a25f`) — баг от Михаила
  Андронова: редактор давал союзнику (Changecaster в CSM) улучшения и флаг Warlord, проверка
  потом ругалась. Общая функция `allyBars` (rosterEngine) для редактора (`fieldProps.allyBarsOf`
  → RosterEntryFields) и `validateRoster`; группа с `enh` от appdata улучшения разрешает (11 армий).
- **Be'lakor-союзник не обязан быть Warlord** (`fc718693`) — решение владельца: правило союзников
  сильнее SUPREME COMMANDER. `mustBeWarlord` — автоназначение и проверка `supremeCommander*`.
- **Экспорт «Русский турнир»** (`feat/export-rus` → `feat/export-rus-hyper`, `b7c5818b`) — запрос
  Creego. Формат по правилам клуба владельца Ordo Eventus: шапка `PLAYER NAME / ARMY NAME / HIN /
  FACTION KEYWORD / DETACHMENT / FORCE DISPOSITION / TOTAL ARMY POINTS / WARLORD / ENHANCEMENT`,
  `Attached Unit N:`, префиксы EH CH BL IN MO BE VE MN DT FO AU, `(N)` только у переменного
  размера, только сменное снаряжение. Поля «Игрок» и HIN в окне экспорта (localStorage).
  Регламент Hyper/HEAT (`sources/y.pdf`) — то же короче. `.ros/.rosz` НЕ делаем: настоящий
  требует id каталогов BSData; 40001format.xyz застрял на 10-й редакции.
- Чейнджлог 2.8.2 написан (оба фикса, формат). Название «Русский турнир» владелец просил пока
  оставить, «позже поменяем» (варианты: «Турнирный (HIN)», «Для турниров в России»).

- **Экспорт «Русский турнир» печатает только замены** (`7ae045d8`, прямо в release) — замечание
  проверяющего: «2x Melta Rifle, 1x Multi-melta» у Eradicator. Решение владельца: только сделанные
  замены с числом моделей, оставленное и фиксированное не пишем.
- **Стрелка нативных селектов** (`5c6fac0e`, прямо в release) — у всех пяти `<select>` своя
  стрелка с отступом (`appearance: none` + шеврон фоном, обе темы), селекты остаются нативными.

Проверки на ветках: typecheck, lint, тесты конструктора/данных (последний прогон беты 2538 зелёных).
