# Жалоба: «версия 2.4 висела, пока не почистил кеш»

Дмитрий Башкирцев (Telegram, 2026-09-21, ~00:00): автообновление «не отработало», приложение
сидело на 2.4 до чистки кэша. Прод на тот момент — 2.6.4 (восемь релизов 2.4.1…2.6.4).

## Проверено — сервер чист

- `sw.js` → `no-cache`, `manifest.webmanifest` → `no-cache`, `index.html` → `max-age=3600`,
  `registerSW.js` не эмитится (регистрация в бандле через workbox-window) — всё как в `DEPLOY.md`.
- CDN чистится `/*` на каждом деплое (`deploy.sh` шаг 4). Прод отдавал `index-DAgZlMkM.js` = 2.6.4.
- Прод-`sw.js`: есть обработчик `SKIP_WAITING`, `cleanupOutdatedCaches`; `clientsClaim` не нужен —
  при активации нового SW контролируемые клиенты переходят к нему и `controllerchange` стреляет.
- Цепочка workbox-window → `installed`/`waiting` → `needRefresh` → `messageSkipWaiting` →
  `controlling` → `reload` прогнана по прод-бандлу, рабочая. Код `UpdateToast.vue` не менялся с
  2.4.0 — у Дмитрия крутилась та же логика.

## Причина — исключение по маршруту в установленном PWA

`UpdateToast.vue`: `if (pwaInstalled && onActiveGame()) return`, где `onActiveGame` =
`path.startsWith('/tracker/game')`. Проверялся **путь, а не партия**: форма настройки,
завершённая и идущая партия — всё на `/tracker/game`; resume-view при запуске возвращает на
последний путь. Игрок, живущий только в трекере, с этого пути не уходит → каждый новый SW
встаёт в `waiting`, апдейт откладывается вечно. Ждущий SW активировался бы при закрытии *всех*
клиентов сайта, но одной забытой фоновой вкладки на Android хватает, чтобы этого не случилось.
Во вкладке (не PWA) исключения не было — там обновление применялось сразу; Дмитрий почти
наверняка на установленном PWA (не спрашивал — можно уточнить для подтверждения).

## Решение владельца — исключение убрать целиком

Реальная цена перезагрузки мала: `useTracker` сбрасывает сохранение на
`pagehide`/`beforeunload`/`hidden`, resume-view открывает тот же экран; теряется только открытая
модалка / недопечатанная заметка. Сделано, коммит `894d067` в wh11ed `main` (**не запушен, не
задеплоен**):
- `UpdateToast.vue`: убраны `pwaInstalled`, `onActiveGame`, импорт `stripLocale`; `applyIfSafe` →
  `apply`; на навигацию остался только `checkSW` (обёрнут в замыкание — `checkSW` переприсваивается
  после регистрации);
- `DEPLOY.md` §Updates переписан, добавлено «не возвращать отсрочку по маршруту»;
- запись 2.6.5 в `changelog.js` **целиком сжата** по правке владельца (без «спасибо игроку»,
  без объяснения Leader+Support и перечня сносок) и дополнена пунктом про обновление.

Проверки: `vitest useUpdateNotice` 5/5, eslint чисто, `npm run build` зелёный.
