# Аудит пропущенных классов ошибок (после отчётов о подставках и Hulking Brutes)

Повод: два отчёта за день — Blue/Brimstone Horrors на 32mm и Hulking Brutes без части за 2CP — оба
оказались не единичными ошибками, а слепотой конвейера (сборка appdata теряла столбцы, раздача
размера подставки по профилям). Владелец попросил пройти журналы и найти, что ещё могло ускользнуть.
Четыре помощника (только чтение): активные+отложенные журналы, архив, 103 урока, столбцы appdata.

## Главный вывод

Почти всё найденное — не «ошибка в данных», а **гейт, который не видит**:
- сборка appdata (`build-factions.mjs`) теряла: второй эффект стратагемы, `key` (чей ход),
  `subtitle` компонентов (D6 у Code Chivalric), аккордеоны с номером «5.3.2»/«24.37.01», строки
  `bullets` (Brood Brothers 500/1000/1500);
- генератор ростера не читал: `maxModelCount`, требования улучшений к способности/оружию, условия
  «с таким-то датащитом в армии» (Cato Sicarius), строку MFM «1 модель» у необязательной модели;
- `npm run sync` всегда выходил с 0: 32 FLAGGED ждали с 2.9.6, почти все — ложные (отчёты не читали
  плашку `extras`, сравнивали копии Combat Patrol, мостили Faction Pack лист по чужому id);
- паритет FAQ фракций проверял 0 из 616 записей (читал `items`, а данные в `entries`);
- `omissions` пропускал правило без пары под его номером.
