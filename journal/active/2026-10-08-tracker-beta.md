# Бета нового трекера на beta.wh-rules.ru + релиз 2.7.19

## Решения владельца (2026-10-08)

- Бета — поддомен `beta.wh-rules.ru`, сборка из ветки `feat/tracker-side-cards`; на основном сайте старый трекер.
- Запуск беты — вместе с обычным вечерним релизом 2.7.19 **сегодня**.
- Разными версиями играть нельзя: **запрет на сервере** + оповещение гостю «откройте партию по ссылке в версии хоста».
- Всё, что из ветки трекера можно вынести без самого трекера, идёт в 2.7.19.
- Инфраструктура (бакет, CDN, сертификат, DNS) — позже, сначала код.

## Устройство запрета

- Партия несёт поколение трекера в общем срезе: `trackerGen` (бета пишет 2; нет поля — 1).
- Клиент шлёт своё поколение в `/party/join` (`gen`; нет поля — 1, это телефоны ≤2.7.18).
- Сервер при несовпадении: 409 `{ error: 'tracker_version', gen }`; клиент по `gen` знает адрес версии хоста.

## План

1. api: проверка поколения в `/join` (+ `/reclaim`), тест; выкладка — по «да».
2. wh11ed `release/2.7.19`: вынос общих изменений из ветки трекера; `gen: 1` в join + сообщение; партия из беты в истории не продолжается; чейнджлог.
3. Ветка беты: влить релиз, `trackerGen: 2`, сообщение, noindex, плашка беты, имя PWA, `.env.deploy.beta`.
4. Смоук, выкладка api → прод → бета.
