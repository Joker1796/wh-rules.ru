# Свой вход, не только Яндекс

Повод: игрок с несколькими аккаунтами Яндекса не может выбрать аккаунт — сайт сразу входит под тем,
что открыт в браузере (Михаил, 2026-10-09). Раньше: `unauthorized_client` у детских аккаунтов и
аккаунтов организаций — Яндекс таких не пускает вовсе.

Быстрая мера отдельно от этой задачи: параметр `force_confirm=yes` в `oauth.yandex.ru/authorize`
(`wh11ed-api/src/config.ts`) — Яндекс всегда спросит, под каким аккаунтом войти. Правка api, выкат по «да».

Варианты своего входа (не выбраны): вход по коду на почту (без пароля; нужен почтовый канал — Postbox
уже есть для фидбека), пароль (хранение хэшей, сброс), ещё OAuth-провайдеры (VK ID, Google). В api уже
есть слой провайдеров (`ProviderName`, `oauthProvider()`), сессии и refresh-токены от провайдера не зависят.
