# Проход по анимациям: отклик на палец, свёртки, сдвиги, переходы страниц

Владелец попросил «посмотреть, где можно добавить анимации (кроме трекера)», дальше — по его
замечаниям со скриншотов, одно за другим. Всё лежит в одном коммите wh11ed `b003f6e` (main, не
пушен, **не в проде**; прод — v2.7.4). Как устроено — в `wh11ed/src/components/CLAUDE.md`
(раздел Motion, переписан), `src/views/faction/CLAUDE.md`, `src/views/combat-patrol/CLAUDE.md`.
Здесь — решения и где остановились.

## Решения владельца (не выводятся из кода)

- **Всё — и телефон, и десктоп.** Спросил прямо; ответ: везде. Только по смыслу телефонное
  (выезд «К партии», нижнее меню, шторка окна) остаётся телефонным.
- **Отклик кнопок:** обычные кнопки, «+» каталога, переключатели шапки, кнопка «i» — простое
  проседание без колыхания (сначала колыхание было везде, владелец попросил убрать; у «i» —
  проседает вся кнопка, не иконка). Булавки/звёздочки/чекбоксы — проседание при нажатии,
  пружина с колыханием при отпускании. Первая версия «рывок на увеличение» отвергнута.
- **Закреплённая фракция уезжает из своей группы** и переезжает в «Закреплённые» одной карточкой
  (не стоит в двух местах) — во всех четырёх списках фракций.
- **Счётчики** — число «прокручивается как колёсико»; **размер отряда** — нажатие + плавная смена
  выделения; **очки ростера** — «начисление» (цифры бегут), вспышку цветом владелец не заметил.
- **Переключатели `.seg`** — бегунок; у их кнопок нажатия нет (плашка вылезала из-под кнопки).
- **Переходы страниц по схеме:** вглубь — справа, назад — слева, между разделами — растворение,
  «К партии»/«К ростеру» — подъём снизу; на iOS шаги по истории — растворение (свайп Safari).
- **Combat Patrol:** карточки в цвете фракции; страница набора — четыре вкладки (Правила /
  Стратагемы / Улучшения / Юниты), отступы как у страницы фракции.
- **Содержание правил прокручивает, а не телепортирует** — своя прокрутка с пересчётом цели,
  дальний прыжок «перенос + доезд последнего экрана». Поиск и приход с другой страницы — мгновенно.
- **Страницы фракции — вложенные маршруты** (шапка и вкладки стоят, едет содержимое) +
  предзагрузка данных в роутере. Выбрано из трёх вариантов (А), после того как первая схема
  дала «сдвиг всей страницы + резкое появление» — причины были в устройстве страниц, не в
  производительности (кадры ≤33 мс при 4× замедлении).

## Ловушки, найденные по дороге (в CLAUDE.md записаны, тут — коротко)

Класс анимации на кнопке стирается Vue при смене `:class` → только Web Animations; `transform` на
странице делает `position: fixed` внутри неё «плавающим» → сдвиг через `left/top`; `display` у
`ChevronIcon` инлайном перебил `display:none` узкой панели → `:where()`; комментарий перед корнем
вью = Fragment (упал тест `RosterUnitList`); `ResizeObserver` первым вызовом ломал первый слайд
`.seg`; сброс прокрутки при переходе надо делать в момент `@enter`, а не после leave (документ
сжимается, `scrollTo` обрезается, браузер возвращает старый offset); `history.state.position`
вместо `popstate` для распознавания «назад».

## Где остановились

Последняя правка — вложенные маршруты фракции + предзагрузка. Проверено в Chrome с эмуляцией
iPhone 13 покадрово (шапка — тот же узел, содержимое в первом кадре, прокрутка меняется один раз);
**владелец итог ещё не смотрел** — до этого жаловался на дёрганье именно вкладок фракции.

Не проверено на настоящем Safari: WebKit для playwright не установлен
(`npx playwright install webkit`, ~100 МБ) — владелец просил «проверить, чтобы не было багов на
iOS». Полный `a11y` (144 загрузки) зелёный, 2142 теста, lint, dupes, radii, build.
