# Что из правил GW мы не отслеживаем

Повод: 17 FAQ базовых правил выпали незамеченными (репорт 19aa8659, исправлено в 2.8.1, гейт
`corefaq`). Аудит: каждая поверхность `src/data` → откуда берётся → что её сверяет.

## Сверка данных с appdata

- Под гейтом: текст базовых правил (`omissions`), FAQ + эррата базовых правил (`corefaq`, новый),
  таблицы эррат характеристик, dp/диспозиции (MFM), теги оружия, правила датащитов, картинки в
  правилах, core-гранты, id датащитов, исключения, выделение, раскладки (APK), PDF Event Companion.
- Генерируется с `--check`: FAQ фракций (620 записей, RU 618), Legends-проза, ростер, ключевые
  слова, индексы. Свежие.
- **Только отчёт, с шумом**: миссии/твисты/базовые стратагемы (`sync-tracker`, 88 строк
  перефразировок), Combat Patrol (54), опции снаряжения (37), союзники (37), карточки детачментов (36),
  appdata-структура (59), текст фракций (35). Реальная правка здесь тонет — как 09.07 в июне.
- **`npm run sync` выходит с кодом 0 даже при красном гейте** (печатает ✗ в итоге). В CI сверка не
  идёт (appdata приватная) — гейты кусают только при ручном прогоне.
- **Legends из Faction Pack PDF**: письмо-сторож ловит перевыпуск документа, но текст наших
  pack-листов с PDF не сверяет ничто.

## Страница изменений правил (/patches)

Видит: текст базовых правил, бандлы фракций, MFM, FAQ фракций. **Не видит:**
- FAQ и эррату базовых правил (`tables/faq.json`, Core Rules): 931 +14 вопросов, 963 +5 (ещё 10
  правок в 963 — только снятые префиксы «Q:/A:», не новость);
- `factions/_core-content.json` (миссии, твисты, базовые стратагемы, размеры битв, матрица
  диспозиций) — фильтр отсекает файлы на `_`; по существу не менялся ни разу (963 — порядок);
- Event Companion из PDF (26.08: 27 раскладок, 4 FAQ колоды) — в ленте 931 нет;
- Faction Pack (Legends).

## Предложения (ждут владельца)

1. `npm run sync` → ненулевой выход при красном гейте.
2. /patches: дифф FAQ/эррат базовых правил (без косметики «Q:/A:») и `_core-content` по id.
3. /patches: строки об обновлении Event Companion из `companion-pdfs.json` (версия + WHAT'S NEW).
4. Шумные отчёты → baseline + гейт (как `ruletext`): миссии первыми.
5. Faction Pack: версия PDF в гейте (как `companions`), повод перечитать pack-листы.
