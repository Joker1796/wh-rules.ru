# Релиз 2.6.4: «назад» на телефоне, покрытие поиска

## Что вошло

1. **Жест «назад» в установленном приложении закрывал его** (жалоба игрока в чате, 2026-09-20).
   Причина — не модалки, а гвард `router/index.js` «сохранённый RU → префикс /ru»: он возвращал
   редирект с `replace: true`, а у vue-router `replace` из редиректа перекрывает режим вызова, так
   что каждый тап по голой ссылке (`to="/rules"`, ~170 штук) заменял единственную запись истории.
   В EN не воспроизводилось. Теперь `replace` только при `from === START_LOCATION`, иначе ключ не
   передаётся (с `replace: false` ломались явные `router.replace`). Тесты в `router/locale.test.js`.
   Первый заход (модалки) был по неверной гипотезе — урок в памяти `feedback_back_gesture_history`.
2. **Back закрывает открытое окно** — `useBackToClose.js` через `useModalA11y` (все 46 модалок +
   поиск) и `useBackToCloseWhile` для выдвижного меню в `App.vue`. Копия записи истории при
   открытии; окно, которое закрывается и переходит (поиск → результат), оставляет «мёртвую» копию,
   которую слушатель перешагивает. Инвариант — `src/components/CLAUDE.md` («Modals»).
3. **Поиск: FAQ и эррата фракций по заголовку** — `scripts/gen-faction-faq-search-index.mjs` →
   `factionFaqSearchIndex.js` (1188 заголовков, 231 КБ / 39 gzip), `npm run faq:index`, гейт
   свежести в `npm run sync`, шаг в DATA-SYNC §3. Результат → `/factions/<slug>/faq#ffaq-<i>`,
   `FactionFaqView` переключает панель и доскролливает. **Справка** `/help/:topic` — в статическом
   индексе, корень вью несёт id темы. Текст справки про поиск дописан.
4. **Примеры в пустом поле поиска** — `useTypingPlaceholder.js` (печать/пауза/стирание, стоп под
   reduced-motion), призрачный слой с курсором в `SearchModal`; списки `ui.searchExamples` EN/RU,
   гейт в `useSearch.test.js`: каждый пример обязан давать хит с именем в первом результате.
   Решения владельца: без префикса, короткие RU-примеры, «Термосы» → «Ктан».
5. **Меню настроек на телефоне** — `width: max-content` + `<wbr>` перед `@`; **плашка обновления** —
   номер версии в светлой теме (`strong` глобально тёмный).

## Не сделано / хвосты

- Back-поведение проверено только в jsdom; на реальном Android-PWA не прогонялось (юниты →
  назад; поиск → результат → назад за одно нажатие).
- Аудит покрытия поиска: не индексируются тела стратагем/улучшений (только имена), способности и
  оружие датащитов, тексты миссий, глоссарий (249 терминов) — по запросу.
- Текст поста для ВК выдан в чате 2026-09-21, публикует владелец.
