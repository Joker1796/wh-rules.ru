## Путь к установке — ветка `feat/install-path` (`6f0716f3`, `8e903f23`, `ecbf42be`), поверх main
Решение владельца: первый визит — это САЙТ, установку предлагать по пользе.
- Приветствие: «бесплатный сайт…», без пункта про установку; в установленном приложении не показывается.
- `installPath.js` + `InstallOffer.vue`: плашка один раз — после сохранённого ростера, партии или
  3-го визита; не на `/tracker/game`, `/tracker/join`, `/roster/new`, редакторе ростера; раз за
  сессию до ответа. Айфон с работой в Safari без входа — «сначала войдите» (у PWA на iOS своё хранилище).
- `AppFirstRun.vue`: первый запуск установленного — «скачивает для офлайна»; пустой айфон без входа —
  «ростеры из Safari не переезжают, войдите».
- Справка «Офлайн и установка» переписана под путь (в этой ветке; с `fix/help-current` разные разделы).
- Стенд: `?preview=offer|offer-ios|first|first-ios` (только dev).
- Проверено playwright: айфон Safari → установленное, Android 3 визита → «Установить», десктоп.
  Через расширение не вышло — окно Chrome расширения скрыто (`visibilityState: hidden`).
