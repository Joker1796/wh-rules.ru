# sources/ — исходники, кладутся руками

**Эта папка под гитом, её содержимое — нет.** Отслеживается только этот README
(см. `/.gitignore`: `/sources/*` + `!/sources/README.md`), поэтому после клона папка
существует, но пустая — материалы нужно положить сюда самому.

Причина: здесь ~5.5 ГБ PDF, картинок и архивов. В гит это не поедет, да и книги GW
раздавать публично нельзя. При этом папка не должна исчезать из проекта — на неё
завязаны скрипты извлечения.

## Что лежит сейчас

| Путь | Что это | Объём |
|---|---|---|
| `codex/{chaos,cm,imperium,xenos}/` | Кодексы (в основном 10 ed), по группам фракций | ~5 ГБ |
| `Faction pack 11 ed/{chaos,cm,imperium,xenos}/` | Faction packs 11 ed — перекрывают кодексы | ~344 МБ |
| `index_xenos/` | Index-книги (сейчас только `Xenos - Necrons.pdf`) | 19 МБ |
| `Vse_pamyatki_i_glossarii_po_vakhe.docx` | Глоссарий сообщества по переводу | 4.9 МБ |
| `Архив/fonts/` | `SaarSPDemo.otf` — узкий дисплейный шрифт с кириллицей, для RU-баннеров фаз | — |
| `Архив/illustrations/` | Старые вырезанные иллюстрации | ~109 МБ |
| `скрины/` | Рабочие скриншоты | — |

Приоритет источников при расхождениях (для правил фракций): **MFM > Faction Pack > Codex**.

## Чего сейчас нет, но на что ссылается документация

`wh11ed/CLAUDE.md` описывает извлечение из двух PDF, которых в папке **больше нет** —
если понадобится что-то перевырезать, их нужно положить сюда:

| Ожидаемое имя (маска) | Зачем |
|---|---|
| `WH40k_11ed_CORE-Rules_*.pdf` | тексты правил (`pdftotext -layout`), жирные прогоны (`pdftohtml -s`), перевырезка иллюстраций (`pdftoppm -r 600`) |
| `eng_12-06_warhammer40000_event_companion-*.pdf` | картинки Event Companion: раскладки, иконки, эмблемы (pymupdf) |

Имена содержат даты/версии, поэтому в документации они матчатся по маске, а не по точному
имени. Учти также: `wh11ed/CLAUDE.md` упоминает шрифт как `sources/fonts/` — фактически он
лежит в `Архив/fonts/`.

## Что от папки зависит

- **`wh-glossary/scripts/extract.py`** — ждёт docx по пути
  `../sources/Vse_pamyatki_i_glossarii_po_vakhe.docx` (можно передать аргументом).
  Без него нельзя перегенерировать словарь, но уже извлечённые `terms/*.tsv` закоммичены
  и работают без исходника.
- **`wh11ed`** — только разовые извлечения текста и картинок. В рантайме и в сборке
  `sources/` не участвует: всё нужное давно перенесено в `src/data/` и `public/images/`.

**Пустая `sources/` не ломает ни сборку, ни тесты** — она нужна только когда что-то
извлекается заново.
