# Приложение GW в эмуляторе

Приложение — первоисточник того, что показывает игроку GW: эррата («Updates & Errata» кодекса),
очки с доплатами, проверка списка. appdata — его дамп, но **эррата приходит в приложение раньше,
чем в наш дамп**, и бывает, что appdata противоречит сама себе (2026-10-03: два текста
Intraneural Biotech — верный нашёлся только в эррате приложения).

## Жёсткие правила

- **В аккаунт GW не входить. Никогда.** На стартовом экране — **SKIP**, на окне Battle Forge —
  **Close**. Регистрироваться, вводить почту — нельзя (решение владельца).
- Без входа Battle Forge держит **ровно один список**. Перед новым — удалить старый (`More Option`
  на карточке → `Delete` → `Delete Army`). В конце работы тоже удалить, чтобы слот был свободен.
- **Датащиты без входа закрыты** («Locked content»): статы, Leader-списки и т. п. в приложении не
  прочитать — только в appdata. Открыты: детачменты (правила, улучшения, стратагемы), Army Rules,
  FAQs, **Updates & Errata**, а в Battle Forge — очки и сообщения об ошибках списка.

## Инструмент

`.claude/skills/gw-app/emu.sh` — нажимает по **тексту** на экране (uiautomator), а не по координатам.
Задать `SCRATCH` = scratchpad сессии, туда же пишутся скриншоты.

```bash
G=.claude/skills/gw-app/emu.sh; export SCRATCH=<scratchpad>
$G start                       # фоном AVD playstore36, ждёт загрузки, запускает приложение (~1 мин)
$G tap "^SKIP$"                # без входа
$G tap "^Codex: Imperial Agents$"; $G texts     # что на экране
$G shot errata                 # скриншот → errata.png и уменьшенный erratas.png (читать его)
$G stop                        # в конце
```

`tap "<regex>" [n]` — n-й совпавший элемент (0 — первый); `NOT FOUND` печатает, что нашлось похожего.

## Грабли (каждая стоила попытки)

1. **`texts` теряет длинный текст.** uiautomator отдаёт только видимые узлы, а повторяющиеся строки
   («Change to:») при склейке экранов выпадают. Эррату и длинные правила **читать скриншотами**:
   промотать к началу (`swipe-down` раз 15), дальше `shot` → `swipe-up 600` по кругу. Читать
   уменьшенный `*s.png` — картинки дороги.
2. **Группы в списках сворачиваются по тапу.** В Allied Units три группы (Imperial Knights, Titan
   Legions, Imperial Agents); тап по раскрытой её сворачивает. Надёжнее **поиск**: `tap "Search"`
   → `type "Inquisitorial"` → тап по заголовку группы (≈ `input tap 540 465`) → появится юнит.
3. **Создание списка — пять шагов, и каждый молча не пускает дальше:** фракция (листать к ней) →
   размер битвы → детачмент + `CONFIRM DETACHMENTS` → **выбрать Force Disposition** (без этого
   `CONTINUE` ничего не делает) → **ввести название** (`tap "Enter Army Name"`, `type "Test"`) →
   `CREATE ARMY`.
4. **Добавление юнита**: `Add Unit` по номеру секции (0 — CHARACTERS … 4 — ALLIED UNITS), затем
   `Add Unit` у юнита, затем `back`. Цены в каталоге уже с доплатами детачмента (Veiled Blade:
   Eversor 115 = 100 + 15).
5. **Размер отряда** — открыть юнит в списке (`tap "<Имя>"`, это кнопка «Edit unit»), степперы
   `Increase count` по профилям; цена юнита — строка «N Points».
6. **Ошибки списка** — жёлтый треугольник у счётчика очков, внизу слева (`input tap 130 1990`).
   Текст ошибок GW — прямая проверка нашего валидатора: «RETINUE (3) has exceeded the limit (2) –
   excluding those that do not count towards that limit».
7. **Эррата кодекса**: Reference → фракция → `Codex: …` → `Updates & Errata`, вверху дата
   «Last Updated». Сверять КАЖДЫЙ пункт с нашими данными, а не только искомый — в эррате
   Imperial Agents 2026-09-30 было 18 пунктов, три из них вскрыли наши баги.
8. Версия приложения в AVD — 2.7.1. Новый APK: распаковать `.xapk` из `sources/apk/` и
   `adb install-multiple *.apk`.

## Что делать с найденным

- Расхождение appdata с эррата приложения → правка наших данных + запись в
  `wh11ed/scripts/lib/appdata-exceptions.mjs` (источник: «App X.Y → Codex → Updates & Errata,
  пункт …, дата проверки»). Не молча.
- Очки/валидация, которые приложение считает иначе, чем мы → баг конструктора; воспроизвести
  тестом на наших данных до правки.
